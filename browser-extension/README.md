# StepBar Chrome 扩展

这个目录包含扩展源码与连接状态页。当前不是 Chrome 应用商店发布版，需要开启开发者模式加载。

## 推荐：通过 StepBar 安装包安装

运行 StepBar → 设置 → Chrome 扩展 →「安装 Chrome 扩展」→ Chrome 打开 `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」。选择应用准备的目录：

```text
~/Downloads/StepBar-browser-extension
```

选择窗口按 ⌘⇧G 可输入此路径。扩展自动连接，无需填写任何配对信息。完成后在 StepBar 设置中点击「测试连接」，验证扩展真实响应；不会切换或关闭页面。保留这个目录，更新应用后重新加载扩展。

v0.1.1 在 Finder 选中下载目录的扩展。v0.1.0 仍使用 `~/Library/Application Support/StepBar/browser-extension`。Chrome 持续从选定目录加载，安装后不能删除或移动；再次点击安装可刷新导出文件，然后在 Chrome 重新加载。升级时移除旧扩展，再加载新目录。

## 直接加载本仓库目录

1. 下载或克隆仓库，保留此目录。
2. 在 Chrome 开发者模式下加载 `browser-extension` 文件夹，不是单个文件或 ZIP。
3. 开发运行的 StepBar 会在可定位到的源码扩展目录写入本机配对文件，扩展自动读取。若未自动连接，请使用应用「安装 Chrome 扩展」导出的目录，不再手动填写配对信息。
4. 在 StepBar 设置中点击「测试连接」，或点击 Chrome 工具栏的 StepBar 图标查看连接状态。

`pairing.json` 是每台机器自动生成的私有配置，已被 Git 忽略。不要共享此文件；不会使用所有用户共用的固定凭据。

## 权限与故障排查

扩展仅与本机回环地址通信，默认端口 17373，被占用时应用自动尝试 17374–17393，扩展读取实际端口，无需用户配置。上报标签页及停留页面的正文摘录，按应用命令切换／关闭标签页，不读取无痕窗口。需要网站访问权限以读取页面文本，可在 Chrome 扩展设置限制，但限制后相应页面能力可能不可用。

连接失败时检查 StepBar 正在运行、扩展连接已启用且未暂停；重新点击「安装 Chrome 扩展」并在 Chrome 重新加载，再测试连接。全新重装时移除旧扩展再加载新目录，避免重复。未装扩展时 StepBar 仍可搜索 Chrome 历史。

完整步骤见 [安装与使用指南](../docs/INSTALL.md)。
