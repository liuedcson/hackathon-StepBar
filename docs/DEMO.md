# 三分钟演示

开场说明：**StepBar 是轻量级办公 Toolbar，帮助更快进入工作入口；Chrome 是当前的第一个验证场景，而不是永久的平台边界。** 只演示浏览器闭环，不把跨平台、跨应用 MCP 和下一步预测当成现有功能。

演示前：启动 StepBar，在 Chrome 中加载扩展，并正常浏览过 GitHub、知乎、StepFun 文档等页面。

版本确认：公开下载仍为 **v0.1.8**，下列新检索规则仅在未发布源码自建版演示。用隔离演示数据，提前确认 Step 5 notes 与语音配置，不为演示擅自读取真实凭据／历史；联网结果不可保证每次相同。

1. **可靠入口（30 秒）**：⌘M，输入 `github apple/swift` 展示确定性直达；再试公开项目查询，观察融合推荐。网络及时且有可靠证据时可选源头仓库，否则明确展示搜索兜底，不保证每次直达官方仓库。
2. **本地剪贴板（30 秒）**：复制一个公开网页地址，⌘M，选择本地建议打开。空输入不调模型，当前页／剪贴板不外发 3.7。
3. **点名站点（30 秒）**：`小红书 国庆去哪里玩`、`大模型会不会让程序员失业 知乎`，都直达站内搜索。
4. **语义匹配（30 秒）**：输入 `阶跃 api 是啥`，标题里没有这些字，也能找回看过的「基本概念」文档。打开「Step 的理解与记忆 → 页面理解」，展示后台为它写的用途和问法。
5. **回忆与学习（30 秒）**：使用预置数据输入 `昨天看的 Swift`，展示原始标题匹配与时间过滤；再查看「学到的选择」和「网址模式」。选择只给已相关项加权，不承诺无关页面被置顶。
6. **语音（30 秒）**：先唤起，在面板内长按 ⌥M 说「deepseek 的 github」，松开即出结果。

收尾愿景：未来通过用户授权的 MCP 或应用适配器，把工作上下文连接起来，整理常用路径与工具组合。例如看到团队消息中的服务告警，唤起时即可选择相关指标、日志和排查资料。**这个跨应用场景尚未实现**；核心是让用户少寻找、少切换、更快进入下一步，而非未经确认自动处理问题。

注：语音核心转写已通过合成音频实测，现场录音应提前验收；生成海报与概念图需标明示意，不混入上述真实操作证据。

源码优化说明：150 ms 防抖、联网软等 1.2 秒、最多 5 个融合候选不是总响应保证；晚搜索仅缓存，不追加模型请求。合成准确率不能作为真实演示或用户历史指标，详见 [三层检索](RETRIEVAL.md)。
