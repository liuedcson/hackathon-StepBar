# StepBar Chrome 扩展

这个目录就是可加载的扩展源代码，包含 `manifest.json`、后台脚本、配对页和图标。当前不是 Chrome 应用商店发布版，需要开启开发者模式加载。

## 推荐：通过 StepBar 安装包安装

运行 StepBar → 设置 → Chrome 扩展 →「安装 Chrome 扩展」→ Chrome 打开 `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」。选择应用准备的目录：

```text
~/Downloads/StepBar-browser-extension
```

选择窗口按 ⌘⇧G 可输入此路径。应用会写入本机配对码，扩展自动连接。保留这个目录，更新应用后重新加载扩展。

v0.1.1 在 Finder 选中下载目录的扩展。v0.1.0 仍使用 `~/Library/Application Support/StepBar/browser-extension`。Chrome 持续从选定目录加载，安装后不能删除或移动；再次点击安装可刷新导出文件，然后在 Chrome 重新加载。升级时移除旧扩展，再加载新目录。

## 直接加载本仓库目录

1. 下载或克隆仓库，保留此目录。
2. 在 Chrome 开发者模式下加载 `browser-extension` 文件夹，不是单个文件或 ZIP。
3. StepBar 设置 →「Chrome 扩展」，确认桥接开启，复制配对码。
4. Chrome 工具栏点 StepBar 扩展，或从扩展详情进入「扩展程序选项」。
5. 在配对页填写配对码，点击「保存并连接」，检查状态为「已连接」。

`pairing.json` 是每台机器的私有配置，已被 Git 忽略，没有提交是正常现象。不要共享配对码。源码目录没有配对文件时，可以用上述手动配对方式。

## 权限与故障排查

扩展与本机 `127.0.0.1:17373` 通信，上报标签页及停留页面的正文摘录，按应用命令切换／关闭标签页，不读取无痕窗口。需要网站访问权限以读取页面文本，可在 Chrome 扩展设置限制，但限制后相应页面能力可能不可用。

连接失败时检查 StepBar 正在运行、桥接开启、配对码一致；重新加载扩展或重新保存配对码。全新重装时移除旧扩展再加载新目录，避免重复。未装扩展时 StepBar 仍可搜索 Chrome 历史。

完整步骤见 [安装与使用指南](../docs/INSTALL.md)。
