# v0.1.8 发布与升级验收

## 发布

执行 `STEPBAR_TEST_UI=1 ./scripts/test.sh` 和 `./scripts/package-release.sh`。发布前检查 ZIP：仅包含 StepBar.app、图标、扩展源码、更新与卸载脚本；不含本机配置、配对码、浏览历史或签名私钥。固定签名证书私钥保留在发布者本机，禁止上传。

将 `build/release/StepBar-0.1.8-arm64.zip` 和 `update-arm64.json` 上传至 GitHub Release `v0.1.8`。不公开本机草稿和旧备份。只发布 Apple Silicon 包；Intel 需要在对应机器构建并发布 `update-x86_64.json`。不覆盖已有标签与资源。

本版修复传统钥匙串后台读取反复弹授权窗口：读取时禁止交互并恢复原策略，无授权返回空，显式保存仍可授权一次。旧条目若不信任当前签名，需用户重新填写并授权，不自动删除或放宽访问权限。真实旧条目重授权后跨版本静默行为仍需现场验收。

免费 DS／GLM review 后修复历史读取失败误清记忆、损坏记忆与设置的备份保护、暂停读取、历史加载新增竞态、删除抑制、JSON 密钥和输入脱敏、模型猜测私网动作、部分用量计数、模式切换 Key 草稿和标签页标题刷新。截断页面批次最多减半重试一次，不提高输出上限。扩展缓存实际端口，401 提示重新加载。

安装工具先复制 incoming 并验签，再换位，失败尝试回滚。SIGKILL／断电仍无法保证两次 rename 间的自动恢复，不宣称任意中断均安全。应用更新后再次点击「安装 Chrome 扩展」刷新导出文件，并在 Chrome 重新加载扩展。

保留 v0.1.6 的隔离运行更新目标选择与失败提示，不清除隔离属性、不关闭 Gatekeeper。v0.1.5 及以前若因隔离运行无法更新，需一次手动安装最新版。

保留 v0.1.5 的 Token usage、Chrome 心跳 Ready、历史本地 ID 模板与定时定量 AI 准备；设置仅「设置／记忆」两页。

保留原生更新确认、后台校验、安装工具就绪握手与本机日志；语音唤起后长按 ⌥M，暂停门控与桥接 FIFO 不变。扩展 manifest 版本独立维护。

## 干净重装

安装包用户可执行 `/bin/zsh "$HOME/Library/Application Support/StepBar/uninstall.sh"`，输入 YES 后删除应用、记忆、设置、专用钥匙串账户及受管理的扩展目录。保留源码配置和 Chrome 历史；Chrome 扩展列表需手动移除。卸载前请备份需要保留的记忆。

`python3 scripts/reset-local.py` 仅预览；`--confirm` 清理明确列出的 StepBar 应用、运行数据、专用钥匙串账户、配对与构建产物。保留源码、被忽略的 `config.local.json` 和发布签名证书。不会修改 Chrome 用户目录，旧的已加载扩展应在 `chrome://extensions` 手动移除，再加载新扩展。麦克风权限会尝试重置，必要时在系统设置核对。

## 验收清单

- 下载 → 解压 → 移入应用目录 → 首次启动 → 菜单栏与 ⌘M。
- 无配置时本地检索可用，无模型 Key 不发送模型请求。
- 设置官方/自定义后台和前台，独立连接测试成功；自定义搜索与语音默认关闭。
- 安装包自带扩展，生成新配对码，Chrome 上报标签页、页面用途，切换原标签页。
- 联网搜索过滤个人信息、ID、回忆和链接；自定义 API/音频转写模拟协议测试通过。
- 后台首次立即准备，随后定时定量增量；无需空闲接电，暂停时停止。界面应展示 usage、准备进度与 Chrome Ready。
- 默认自动检查更新，无需 GitHub Token，匿名请求及默认值通过模拟测试；公开后检查真实 Release 与资源下载。
- 原生确认窗口已用临时 AppKit 窗口验证；安装脚本用隔离假应用覆盖替换、签名失败与启动失败回滚、清理及日志，并验证运行路径不同但 PID 存活时禁止替换。目标选择器、取消选择、身份不符、目录不可写与真实跨版本更新仍需现场验收，不宣称已由脚本测试覆盖。
- 新 Store 隔离测试覆盖损坏记忆备份、删除抑制、清空停止学习、暂停不读历史、空历史保全，以及随机合成 service 读取后的钥匙串交互策略恢复。不会读取真实用户凭据。跨版本 ACL 实验脚本仅允许一次性 macOS 账户显式 opt-in，不纳入常规测试。

## 已知限制

未 Apple 公证，首次打开可能需手动放行；完整真实麦克风转写尚未验收；模型网址与联网摘要可能失效；搜索引擎网页入口不是模型联网数据；Chrome 扩展安装与重载仍需用户操作。

## 发布后语音补测

使用 macOS 合成三段语音，转为 16 kHz 单声道 PCM16，调用应用实际 `VoiceInput.transcribe` 与 Step Plan stepaudio-2.5-asr，再将返回文本送入共享 `Layers` 搜索。三例分别为「阶跃 API 文档」「知乎 大模型会不会让程序员失业」「GitHub Swift」。真实转写全部非空且正确。

初测 2/3 搜索通过：中文转写自动省略站名后的空格，原站内搜索依赖空格。源码补充中文站名首尾匹配及回归测试后，重新调用真实转写，3/3 搜索通过。v0.1.1 纳入该修复，v0.1.0 保持原样。麦克风与按键录音另行验收，自定义 ASR 未配置真实服务，不能由官方接口测试替代。
